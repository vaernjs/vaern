# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),

## [0.0.1] - 2026-10-14

### Added
- Initial npm scaffold for `vaern` runtime CLI.
- Fallback CLI runner (`bin/vaern.cjs`) with `--help`, `--version`, `doctor`, and `roadmap` commands.
- Capability for platform package binary delegation via `postinstall.cjs`.
- Pre-publish validation script (`scripts/check-publish.mjs`).
