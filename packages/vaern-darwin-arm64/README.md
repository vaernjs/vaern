# @vaernjs/vaern-darwin-arm64

The macOS arm64 binary for [`@vaernjs/vaern`](https://www.npmjs.com/package/@vaernjs/vaern).

Do not install this package directly. Install `@vaernjs/vaern`; npm selects this
package through `optionalDependencies` when the host is `darwin` on `arm64`.
