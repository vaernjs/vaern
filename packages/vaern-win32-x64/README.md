# @vaernjs/vaern-win32-x64

The Windows x86_64 binary for [`@vaernjs/vaern`](https://www.npmjs.com/package/@vaernjs/vaern).

Do not install this package directly. Install `@vaernjs/vaern`; npm selects this
package through `optionalDependencies` when the host is `win32` on `x64`.
